# 株式管理アプリ

保有銘柄を画面上で管理するPythonアプリです。

画面コードは、起動用の `gui.py`、状態管理用の `app.py`、各画面の `views/`、入力画面の `dialogs/` に分割しています。

```bash
cd stock_manager
python3 -m pip install -r requirements.txt
python3 main.py
```

画面の「銘柄を追加」から日本株コード（例：`7203`）を入力すると、まず0株の候補銘柄として登録されます。コードが分からないときは、日本株コード欄の虫眼鏡ボタンからみんかぶの銘柄検索ページを開けます。
一覧の行をクリックすると銘柄を選択できます。売買は「株数を変更」から行い、「全売却」では保有株を0株にして売却代金を現金残高へ戻します。全売却後も銘柄と履歴は残ります。

1株以上保有する銘柄は「保有銘柄」、0株の銘柄は「候補銘柄」に分けて表示します。新しい銘柄は必ず候補銘柄へ追加され、株数を増やすと保有銘柄へ移ります。全売却すると候補銘柄の一覧へ戻ります。保有銘柄・候補銘柄の両画面で、日本語の銘柄名による部分一致検索ができます。

一覧の選択状態は、保有銘柄を緑、候補銘柄をオレンジで表示します。

銘柄一覧は表示領域に収まらない場合、縦・横のスクロールバー、マウスホイール、Macの2本指スクロールで移動できます。Shiftキーを押しながらスクロールすると横方向へ移動します。

一度も売買していない0株の候補は「銘柄を削除」で一覧から削除できます。保有中または売買履歴がある銘柄は、現金残高と履歴を保つため削除できません。

銘柄名と現在株価は自動で取得します。日本株の銘柄名はみんかぶの日本語名を優先し、取得できない場合はYahoo Financeの名称を使用します。既存銘柄の名称も株価更新時に更新されます。データは同じフォルダ内の `stocks.db` に保存されます。

画面上部には仮想資金1,000万円と現金残高を表示します。現金残高は購入代金で減り、売却代金で増えます。

「資金設定」から仮想資金額を変更できます。設定額はデータベースへ保存されます。「現金資金をリセット」は全銘柄の保有株数と売買履歴を消去し、登録銘柄を候補として残したまま現金残高を設定額へ戻します。

銘柄を選択して「株数を変更」を押すと、変更後の保有株数を直接入力できます。1株単位の増減ボタンも利用できます。

メニューの「現在株価を取得」を選ぶと、Yahoo Financeから株価と過去1年実績ベースの配当利回りを取得し、評価額と含み損益を表示します。4文字の日本株コード（数字のみ・英字を含む）の末尾には自動的に `.T` を付けて取得します（例：`7203` → `7203.T`、`285A` → `285A.T`）。

株価更新が終了すると完了ポップアップを表示します。一部を更新できなかった場合は、該当する銘柄名も表示します。

「権利日カレンダー」では、保有銘柄のみを対象に、みんかぶから取得した配当権利確定月を月間表示します。権利付最終日は緑、権利落ち日は赤、権利確定日は青です。表示日は月末基準の予定であり、臨時基準日などは企業発表やJPXの確定情報を確認してください。

カレンダー上の今日の日付は、太い赤枠で表示します。

画面にカレンダー全体が収まらない場合は縦・横のスクロールバーを表示し、Macの2本指スクロールにも対応します。

Tk 9環境では高精度の `TouchpadScroll` イベントを使用し、Macの2本指操作を縦・横のスクロールへ反映します。
